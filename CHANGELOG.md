# Changelog

What changed in each Release, for someone installing a Symmetry Skin in Delta.
Versions follow semver.

## [Unreleased]

## [1.1.0] — 2026-10-27

- Disc: every Skin now has a Disc twin (`…-Disc-…`, "(Dex Disc)" in Delta) with a thumbstick in
  the D-pad's place. The disc centres wherever your thumb lands and tracks the push from there, so
  there is no dead middle and nothing to slide off. Built for steering (Mario Kart) and anything
  you hold a direction in. Install it beside the plain Skin and pick per game: the plain file keeps
  the D-pad for grid movement.
- Disc in both orientations: in portrait it sits in the D-pad's zone; in landscape Advance Full's
  floats over the game as an outline, knob included, DS Full's sits in the band under the top
  screen clear of both screens (plain and Reverse Disc), Color Full's sits on the left rail.
- DS ships plain, Reverse, Disc and Reverse Disc per Theme; Advance and Color plain and Disc.
- The 1.0.0 D-pad Skins are unchanged and ship again under the same names and identifiers.

Verified on t2.

## [1.0.0] — 2026-10-22

- Symmetry: every control a thumb needs, mirrored to both sides, so one
  hand, either hand, has everything. Three Consoles: Advance (Game Boy Advance), DS (plain and
  Reverse, where the touch screen takes the large frame) and Color (Game Boy and Game Boy Color,
  which Delta files under one game type). Each Console has two Layouts, One in portrait and Full
  in landscape.
- Two Themes, for every Console:
  - Dex: red body, dark grey deck, blue rings, white labels.
  - Hero: two forest greens, wood controls, gold rings, a Hylian blue rim.
- Advance One (portrait, one thumb, either hand): full-width screen, mirrored A/B pairs, both
  shoulders in each bottom corner as pills, START / SELECT in each top corner, SAVE and toggle
  fast-forward under the screen, menu bottom centre.
- Advance Full (landscape, two hands): full-height screen, outline D-pad, one A and one B on the
  thumb's arc and START / SELECT floating over the game with a hairline edge, L / R and SAVE /
  fast-forward on the rails.
- DS One (portrait, one thumb, either hand): a large screen over a smaller one; A/B pairs each side
  of a centred D-pad, smaller X / Y above them; on each rail beside the touch screen a quick action
  (SAVE left, fast-forward right) and both shoulders, the near one named for its side; START /
  SELECT in both bottom corners, menu centred. No control touches the touch screen. The touch
  screen's rim carries the Theme's accent edge, so plain and Reverse read apart at a glance.
- DS Full (landscape, two hands): the large and small screens side by side along the top, large
  left (in Reverse the touch screen takes it); D-pad under the large screen, ABXY under the small
  one, START / SELECT between; L / R, SAVE / fast-forward and the menu on the rails.
- Color One (portrait, one thumb, either hand): the game full width at the Game Boy's own 10:9,
  with Advance One's deck under it, control for control: mirrored A/B pairs round the D-pad,
  START / SELECT in each top corner, SAVE and toggle fast-forward under the screen, menu bottom
  centre. No shoulder pills (the Game Boy has none); quick LOAD is in the pause menu.
- Color Full (landscape, two hands): the game at the full height, centred, nothing drawn over it.
  Solid controls on the rails: D-pad on the left, one A and one B on the thumb's arc on the right,
  SAVE then SELECT down the left rail, fast-forward then START down the right, the menu in the
  bottom-left corner. A plain body-colour band along each outer edge for the palm.
- Every D-pad is a small hit frame inside a wide margin: Delta reads direction from the frame's
  thirds, so the dead middle stays small and a rolling thumb stays on the pad.

Verified on t5.
